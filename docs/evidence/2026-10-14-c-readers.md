## Try the reader

Build with `npm run package`, then reload `dist/sharh` in `chrome://extensions`.

1. Open a web article, click Sharh, then **Read current page**. Choose main article, whole page or a CSS-selector region. Paragraph buttons highlight the source tab.
2. Choose **Open PDF or local file** in the panel. Pick or drop HTML/PDF files. PDFs show selectable text, outline links and printed page labels. **Show numbered text** exposes the extracted paragraphs and notes.
3. Choose document, selection, section, chapter or PDF page-range scope. Compare the token estimate and protected-request UTF-8 byte count; this does not send text to a model.
4. Allow a PDF source site to enable `.pdf` auto-open there. Turn it off in settings or choose **Use Chrome's PDF viewer**. File URLs also need Chrome's file-access toggle; picked/dropped files do not.
5. Export documents, then import the JSON into an empty profile to verify offline reopening. Existing conflicting data is kept and the import is rejected atomically.

Scanned PDFs, OCR, passwords, redirects and unusual layouts retain the limits listed in the architecture document. Natural-document and live-provider Phase 1 acceptance remains F-08.
